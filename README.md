# <img width="24px" src="./Logo/256.png" alt="Sonarr"></img> Sonarr (mod)

Sonarr (mod) is an anime-focused fork of Sonarr's v4 develop branch for CJK media.

Inspired by [Improve Searching For Anime Seasons #6495](https://github.com/Sonarr/Sonarr/issues/6495) by [Ravencentric](https://github.com/Ravencentric).

### Changes
* Uses XEM aliases when searching for seasons, no longer searches for individual episodes.
* Adds **Indexer > Advanced > Disable Individual Episodes** for disabling individual episode searching per-indexer.
* Adds **Indexer > Advanced > Rate Limit** for changing per-indexer request rate limits, defaults to 2.0.
* Adds **Title SxxEyy** style searches to generic Newznab and Torznab indexers for better results.
* Renamed **Anime / Absolute** to **Anime** to accurately reflect the changes made.
* Adds **Media Management > Advanced > Use Softlinks instead of Copy** for symbolic linking on import.

### Warning
Do not contact the Sonarr developers or use their official support channels for support with this mod as they won't be able to help you.
